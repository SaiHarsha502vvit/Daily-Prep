# Folder Context: 13_Developer_Essentials

## Purpose

Teach developer tooling and operational basics: Git, Docker, CI/CD, networking, servers, ports, concurrency models, and debugging.

## Writing Style

- Practical commands and workflows.
- Production failure modes.
- Clear mental models for tools.
- Short examples with operational consequences.

## Boundaries

Application framework details belong in `07_Modern_Java` or frontend folders. Infrastructure deployment depth belongs in `22_DevOps`.

## Update Triggers

Update this file when tooling ownership, command conventions, or operational topics change.
