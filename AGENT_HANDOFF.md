## 3. Pedagogical Patterns

| Pattern | Marker | Purpose |
|---------|--------|---------|
| 5W1H | `WHY/WHAT/WHERE/WHEN/WHO/HOW` | Chapter opener |
| Theory Lens | `🧠 Theory Lens` | Design problem before solution |
| God-Level Insight | `🔥 3+ YOE God-Level Insight` | Senior-level reasoning |
| Section Challenge | `🔬 Section Challenge` with `<details>` | Interleaved testing |
| Anti-Pattern | `❌ BAD → ✅ GOOD` | Code comparison pairs |
| ASCII Diagrams | Box-drawing characters | Memory/architecture layouts |

**Core Principle**: Depth over breadth. WHY before WHAT. Production context always.
