# Folder Context: 05_Problem_Solving

## Purpose

Organize practice problems by topic and pattern, with applied reasoning and common traps.

## Writing Style

- Problem statement or signal.
- Brute force idea.
- Pattern recognition.
- Optimized approach.
- Edge cases and mistakes.

- Every page carries the standard blocks: Bridge, study-partner explainer (with a **Check yourself** set), Enterprise Lens and Reality Check. The reading order and dependency graph live in [`00_LEARNING_PATH.md`](00_LEARNING_PATH.md); file-name numbers do not follow it.
- Pages longer than ~800 lines are **hubs** with topic pages in a folder named after the page.
- History and "real-world" claims must be attributable. Mark dramatised scenes as illustrative; never present invented incidents, quotes or company details as fact. Company tags are community-reported and unverified.
- Code in problem pages must compile and be compared with a brute force before it is documented.

## Boundaries

Keep this folder practice-oriented. Put deep theory in `02_Data_Structures`, `03_Algorithms`, and `04_Patterns_Templates`.

## Update Triggers

Update this file when problem categorization, practice structure, or topic ownership changes.
