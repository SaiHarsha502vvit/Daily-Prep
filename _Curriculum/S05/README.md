# Semester 5 — Frontend & Developer Experience

| Code   | Course                             | Hours |
| ------ | ---------------------------------- | ----- |
| CSE501 | JavaScript & TypeScript Deep Dive  | ~20h  |
| CSE502 | React & Frontend Architecture      | ~25h  |
| CSE503 | CSS & Design Systems               | ~15h  |
| CSE504 | Frontend Integration & Performance | ~15h  |

**Prerequisites:** [Semester 3 — Software Engineering Core](../S03/README.md)

S05 builds on S03 foundations (OOP, SQL, design patterns). It is parallel with S06 but S05/S06 together satisfy the S07 prerequisite.

## Skills Covered

- Advanced JavaScript/TypeScript (ES2024+, decorators, metaprogramming)
- React 19 with Server Components, Suspense, and concurrent features
- CSS architecture: Grid, Flexbox, Container Queries, Cascade Layers
- Design systems: tokens, theming, accessibility (WCAG 2.2)
- Frontend integration: Webpack/Vite/ESM, bundling, code splitting
- Performance: Core Web Vitals, Lighthouse, profiling, lazy loading

## Study Guide

- Begin with [CSE501](./CSE501_JavaScript_And_TypeScript_Deep_Dive/README.md) for language fundamentals
- Progress through [CSE502](./CSE502_React_And_Frontend_Architecture/README.md) for React architecture
- Continue to [CSE503](./CSE503_CSS_And_Design_Systems/README.md) for CSS mastery
- Finish with [CSE504](./CSE504_Frontend_Integration_And_Performance/README.md) for integration and performance

## Parallel Path

This semester is designed to run alongside [Semester 6 — Backend & DevOps](../S06/README.md). Combined, S05 + S06 provide the full-stack skill set required for Semester 7.
