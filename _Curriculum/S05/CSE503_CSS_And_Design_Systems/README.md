# CSE503 — CSS & Design Systems

**Estimated time:** ~15h  
**Prerequisite:** Basic HTML/CSS (S01 CSE102 or equivalent)

## Description

Mastery of modern CSS from fundamentals through advanced layout (Grid, Flexbox, Container Queries, Cascade Layers) and systematic design system construction. Covers visual design principles, accessibility (WCAG 2.2), and tooling (PostCSS, Stylelint, design token pipelines).

## Learning Outcomes

1. Expert-level CSS layout: Grid, Flexbox, subgrid, Container Queries, logical properties
2. Master cascade, specificity, and inheritance; use Cascade Layers (@layer) for conflict resolution
3. Build design token systems: color, typography, spacing, elevation, motion tokens
4. Implement theming with CSS Custom Properties and dark/light/high-contrast modes
5. Ensure WCAG 2.2 compliance: color contrast, focus management, reduced motion, screen reader support

## Syllabus Outline

| Week | Topic                                                                        |
| ---- | ---------------------------------------------------------------------------- |
| 1    | Modern selectors, specificity, cascade, and @layer architecture              |
| 2    | Flexbox deep dive: axis, alignment, flex-grow/shrink, wrapping patterns      |
| 3    | CSS Grid: explicit/implicit grids, named areas, subgrid, alignment           |
| 4    | Container Queries + logical properties for responsive design                 |
| 5    | Design tokens: naming conventions, tiers (primitive, semantic, component)    |
| 6    | Typography systems: scale, fluid type with clamp(), variable fonts           |
| 7    | Color systems: perceptual uniformity, contrast utilities, palette generation |
| 8    | Motion: transitions, animations, scroll-driven animations, @keyframes        |
| 9    | Accessibility: focus-visible, ARIA roles, reduced-motion, skip links         |
| 10   | Design system documentation: Storybook integration, living style guides      |
