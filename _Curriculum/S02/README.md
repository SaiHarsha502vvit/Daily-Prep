## Learning Outcomes
- Implement and analyze all standard data structures from scratch
- Apply algorithm design paradigms: divide-and-conquer, greedy, dynamic programming
- Analyze time and space complexity using formal asymptotic notation
- Model probabilistic systems and perform statistical inference on data
- Understand CPU datapaths, pipelining, caching, and instruction set architectures

## Syllabus Overview

- **Weeks 9–12:** SQL foundations → advanced, distributed systems & DDD
