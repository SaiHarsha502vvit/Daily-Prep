# CSE202 — Algorithms & Complexity

**Semester:** S02 | **Hours:** ~30h | **Prerequisite:** S01 (CSE101 Discrete Mathematics, CSE102 Programming Fundamentals)

## Description
Algorithms & Complexity teaches the core algorithmic paradigms and the mathematical tools to reason about them. Topics include asymptotic analysis, divide-and-conquer, greedy algorithms, dynamic programming, graph algorithms, NP-completeness, and tractability. The goal is to develop the ability to recognize problem structures and select or derive the right algorithm, not just memorize implementations.

## Learning Outcomes
- Classify any algorithm's time and space complexity using Big-O, Big-Theta, Big-Omega notation
- Apply divide-and-conquer, greedy, and dynamic programming paradigms to novel problems
- Implement BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, and topological sort
- Prove NP-completeness of a problem via polynomial-time reduction
- Use recursion trees and the master theorem to solve recurrence relations

## Syllabus Outline
- Asymptotic notation: O, Ω, Θ, o; recurrence relations; master theorem
- Divide and conquer: mergesort, quicksort, closest pair, Strassen's matrix multiplication
- Greedy algorithms: activity selection, Huffman coding, Kruskal's MST, Dijkstra's algorithm
- Dynamic programming: Fibonacci, knapsack, LCS, edit distance, optimal BST
- Graph algorithms: BFS, DFS, connected components, topological sort, strongly connected components
- Shortest paths: Bellman-Ford, Dijkstra, Floyd-Warshall, DAG shortest paths
- Minimum spanning trees: Prim's, Kruskal's, union-find
- NP-completeness: P vs NP, reduction, SAT, 3-CNF-SAT, graph problems
- Approximation algorithms and heuristic methods
