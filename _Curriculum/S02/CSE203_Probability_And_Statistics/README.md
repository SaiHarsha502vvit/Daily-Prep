# CSE203 — Probability & Statistics

**Semester:** S02 | **Hours:** ~15h | **Prerequisite:** S01 (CSE101 Discrete Mathematics, CSE103 Linear Algebra)

## Description

Probability & Statistics equips computer scientists with the mathematical framework for reasoning under uncertainty. Topics include probability axioms and counting, conditional probability and Bayes' theorem, discrete and continuous random variables, expectation and variance, common distributions (binomial, Poisson, Gaussian, exponential), hypothesis testing, confidence intervals, and regression. Applications include algorithm analysis (randomized algorithms, average-case complexity), ML model evaluation, and A/B testing.

## Learning Outcomes

- Compute probabilities using axioms, counting techniques, and conditional probability
- Apply Bayes' theorem to update beliefs given new evidence
- Identify and work with common discrete and continuous distributions
- Calculate and interpret expected value, variance, and covariance
- Conduct hypothesis tests and construct confidence intervals for real data
- Apply statistical reasoning to randomized algorithms and ML evaluation

## Syllabus Outline

- Probability axioms, sample spaces, events, counting (permutations, combinations)
- Conditional probability, independence, Bayes' theorem, law of total probability
- Discrete random variables: Bernoulli, binomial, geometric, Poisson
- Continuous random variables: uniform, exponential, normal (Gaussian)
- Joint distributions, independence, covariance, correlation
- Expectation, variance, linearity of expectation, law of large numbers
- Hypothesis testing: null/alternative, p-values, Type I/II errors, t-tests
- Confidence intervals, sampling distributions, central limit theorem
- Applications: randomized algorithms, ML metrics (precision, recall, ROC)
