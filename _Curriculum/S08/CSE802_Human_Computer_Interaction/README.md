# CSE802 — Human-Computer Interaction

**Estimated time:** ~15h  
**Prerequisite:** S05 (React & Frontend Architecture recommended)

## Description

Study of the principles and practices of human-computer interaction (HCI). Covers user-centered design, usability heuristics, accessibility standards (WCAG 2.2/2.3), user research methods, prototyping, and evaluation. Students conduct usability studies, perform accessibility audits, and iterate on designs based on empirical feedback. bridges the gap between "works for me" and "works for everyone."

## Learning Outcomes

1. Apply user-centered design methodology: user research, persona development, journey mapping, and requirement gathering
2. Evaluate interfaces using Nielsen's heuristics and the WCAG 2.2 accessibility guidelines
3. Conduct usability testing: think-aloud protocols, task completion rates, SUS scoring, and eye-tracking basics
4. Design accessible interfaces: semantic HTML, ARIA roles, keyboard navigation, color contrast, screen reader compatibility
5. Prototype and iterate: paper prototypes, wireframes, high-fidelity interactive prototypes, A/B testing

## Syllabus Outline

| Week | Topic                                                                                        |
| ---- | -------------------------------------------------------------------------------------------- |
| 1    | HCI history and foundations: cognitive load, Fitts's law, Hick's law, Gestalt principles     |

| 7    | Visual design for accessibility: color contrast (4.5:1, 3:1), text scaling, motion reduction |
| 8    | Screen reader testing: NVDA, VoiceOver, common pitfalls, live region announcements           |
| 9    | Prototyping methods: paper, Figma wireframes, high-fidelity interactive prototypes           |
| 10   | Usability testing: test plans, think-aloud protocol, SUS questionnaire, severity scoring     |
| 11   | Capstone: conduct a full usability study and accessibility audit on an existing application  |
