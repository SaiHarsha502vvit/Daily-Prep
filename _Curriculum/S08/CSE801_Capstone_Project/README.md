# CSE801 — Capstone Project

**Estimated time:** ~40h  
**Prerequisite:** S07 (all advanced topics)

## Description

The capstone project is the culminating experience of the curriculum — a substantial, self-directed project that demonstrates mastery across the full stack: algorithms, data structures, system design, frontend, backend, and operations. Students select a project track from the project bank and deliver a production-quality artifact with full documentation, tests, and a public presentation.

## Learning Outcomes

1. Design and implement a complete, end-to-end system spanning frontend, backend, and data layers
2. Apply algorithms and data structures appropriately: choosing the right tool for the right problem with justification
3. Architect a system for scale: database selection, caching, indexing, API design, and observability
4. Work through a full software development lifecycle: requirements, design, implementation, testing, deployment, and iteration
5. Communicate technical work effectively: documentation, architecture decision records, and a public presentation

## Project Tracks

Students select one track from the project bank:

- [CAP01 — DSA Toolkit](https://github.com/SaiHarsha502vvit/my-prep/blob/main/00_CURRICULUM/PROJECTS/CAP01_DSA_Toolkit.md) — A production-quality data structures and algorithms library with full test coverage, documentation, and performance benchmarks
- [CAP02 — Microservice](https://github.com/SaiHarsha502vvit/my-prep/blob/main/00_CURRICULUM/PROJECTS/CAP02_Microservice.md) — Multi-service e-commerce platform with circuit breakers, event sourcing, and saga orchestration
- [CAP03 — Full-Stack](https://github.com/SaiHarsha502vvit/my-prep/blob/main/00_CURRICULUM/PROJECTS/CAP03_FullStack.md) — Feature-rich web application with React frontend, Spring Boot backend, and PostgreSQL
- [CAP04 — Distributed System](https://github.com/SaiHarsha502vvit/my-prep/blob/main/00_CURRICULUM/PROJECTS/CAP04_DistributedSystem.md) — Distributed key-value store with consensus, replication, and partition tolerance
