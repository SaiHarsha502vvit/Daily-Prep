# Semester 8 — Capstone & Career

| Code   | Course                               | Hours |
| ------ | ------------------------------------ | ----- |
| CSE801 | Capstone Project                     | ~40h  |
| CSE802 | Human-Computer Interaction           | ~15h  |
| CSE803 | Ethics & Professional Practice       | ~10h  |
| CSE804 | Career Mastery & Interview Readiness | ~20h  |

**Prerequisites:** [Semester 7 — Advanced Topics](../S07/README.md)

S08 is the culmination of the curriculum. The centerpiece is a significant capstone project that integrates skills from all prior semesters. Supporting courses round out technical education with human-centered design (CSE802), professional ethics (CSE803), and career preparation (CSE804).

## Skills Covered

- Full-stack system design and implementation from scratch
- User research, usability testing, and accessibility auditing
- Professional ethics, data privacy, AI ethics, and intellectual property
- Technical interviewing: algorithms, system design, behavioral questions
- Career development: resume, portfolio, networking, offer negotiation

## Study Guide

- Begin with [CSE804](./CSE804_Career_Mastery_And_Interview_Readiness/README.md) in parallel with capstone work
- Progress through [CSE802](./CSE802_Human_Computer_Interaction/README.md) for user-centered design
- Continue with [CSE803](./CSE803_Ethics_And_Professional_Practice/README.md) for professional context
- Dedicate the majority of time to [CSE801](./CSE801_Capstone_Project/README.md) capstone project

## Culmination

This is the final semester. The capstone project demonstrates readiness for industry roles and graduate study. Students present their work publicly and compile a professional portfolio.
