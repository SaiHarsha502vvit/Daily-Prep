# Semester 7 — Advanced Topics

| Code | Course | Hours |
|------|--------|-------|
| CSE701 | Compilers & Language Processing | ~25h |
| CSE702 | Distributed Systems | ~25h |
| CSE703 | Machine Learning | ~25h |
| CSE704 | Advanced Algorithms | ~20h |

**Prerequisites:** [Semester 5 — Frontend & DevEx](../S05/README.md) + [Semester 6 — Backend & DevOps](../S06/README.md)

S07 brings together all prior knowledge — systems programming, algorithms, networking, and software engineering — to tackle advanced, cross-cutting topics. Students choose depth in language processing (CSE701), distributed architecture (CSE702), ML foundations (CSE703), or algorithm design (CSE704).

## Skills Covered

- Compiler construction: lexing, parsing, AST construction, type checking, code generation
- Distributed systems: consensus algorithms, replication, partitioning, event sourcing, saga patterns
- Machine learning: supervised/unsupervised learning, neural networks, NLP foundations, model evaluation
- Advanced algorithms: graph algorithms, linear programming, approximation algorithms, randomized algorithms

## Study Guide

- Begin with [CSE704](./CSE704_Advanced_Algorithms/README.md) for algorithmic foundations (supports all other courses)
- Progress through [CSE702](./CSE702_Distributed_Systems/README.md) for distributed systems theory
- Continue to [CSE703](./CSE703_Machine_Learning/README.md) for ML foundations
- Finish with [CSE701](./CSE701_Compilers_And_Language_Processing/README.md) for language processing

## Sequential Path

This semester follows [Semester 6 — Backend & DevOps](../S06/README.md) and [Semester 5 — Frontend & DevEx](../S05/README.md). S07 content directly prepares students for the Semester 8 capstone.
