# CSE302 — Databases & SQL

## Description

Databases are the backbone of every software system. This course covers SQL from fundamentals to advanced optimization, transaction management, query planning, indexing strategies, and analytics — everything from CRUD to performance tuning in production.

## Learning Outcomes

- Write complex SQL: joins, subqueries, CTEs, window functions, recursive queries
- Design normalized relational schemas with proper primary/foreign key constraints
- Understand and optimize query execution plans; use indexes effectively
- Manage transactions, isolation levels, ACID properties, and concurrency control
- Apply advanced analytics: window functions, rollups, pivot tables, time-series queries

## Syllabus Outline

- **Unit 1:** SQL Foundations — SELECT, WHERE, GROUP BY, HAVING, ORDER BY
- **Unit 2:** Joins & Subqueries — INNER, LEFT, RIGHT, FULL, cross-apply, scalar subqueries
- **Unit 3:** Data Modeling — ER diagrams, normalization (1NF–3NF, BCNF), schema design
- **Unit 4:** Indexing & Optimization — B-tree, hash, composite, covering indexes; EXPLAIN plans
- **Unit 5:** Transactions & Concurrency — ACID, isolation levels, locking, deadlocks
- **Unit 6:** Advanced SQL — Window functions, CTEs, recursive CTEs, pivot/melt
- **Unit 7:** Analytics & Big Data — Time-series, rolling aggregates, funnel analysis, hyperloglog
