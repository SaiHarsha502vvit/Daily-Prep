# CSE304 — Numerical Methods

## Description

Numerical Methods provides the mathematical and algorithmic tools to solve real-world problems that lack closed-form solutions. From root-finding and interpolation to numerical linear algebra and differential equations, this course teaches you how to approximate solutions with controlled error — essential for simulations, machine learning, graphics, and scientific computing.

## Learning Outcomes

- Implement and analyze convergence of root-finding algorithms (bisection, Newton-Raphson, secant)
- Apply numerical differentiation and integration with error analysis
- Solve systems of linear equations using direct and iterative methods (Gaussian elimination, LU, Jacobi, Gauss-Seidel)
- Interpolate and approximate functions using polynomials, splines, and least squares
- Implement numerical solutions for ODEs and PDEs with stability analysis

## Syllabus Outline

- **Unit 1:** Error Analysis — Floating-point arithmetic, truncation vs rounding error, error propagation
- **Unit 2:** Root-Finding — Bisection, fixed-point iteration, Newton-Raphson, secant method
- **Unit 3:** Numerical Linear Algebra — LU decomposition, condition number, iterative methods
- **Unit 4:** Interpolation & Approximation — Lagrange polynomials, Newton's divided differences, splines
- **Unit 5:** Numerical Differentiation & Integration — Taylor series, Simpson's rule, Gaussian quadrature
- **Unit 6:** ODEs/PDEs — Euler's method, Runge-Kutta, finite difference methods
