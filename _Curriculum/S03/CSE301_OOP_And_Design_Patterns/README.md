# CSE301 — OOP & Design Patterns

## Description

Object-oriented programming is the backbone of enterprise software. This course deep-dives into SOLID principles, the 23 GoF design patterns, Low-Level Design (LLD), and System Design fundamentals — everything you need to write maintainable, scalable code.

## Learning Outcomes

- Apply SOLID principles to refactor legacy code into clean, extensible designs
- Implement and recognize all 23 GoF patterns in real-world scenarios
- Conduct LLD discussions: class diagrams, dependency injection, interface segregation
- Design systems at scale: load balancers, message queues, caching layers
- Write clean, testable, loosely-coupled code following professional standards

## Syllabus Outline

- **Unit 1:** OOP Foundations — Encapsulation, Inheritance, Polymorphism, Composition
- **Unit 2:** SOLID Principles — SRP, OCP, LSP, ISP, DIP with before/after examples
- **Unit 3:** Creational Patterns — Singleton, Factory Method, Abstract Factory, Builder, Prototype
- **Unit 4:** Structural Patterns — Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy
- **Unit 5:** Behavioral Patterns — Observer, Strategy, Command, State, Template Method, Iterator, etc.
- **Unit 6:** Low-Level Design (LLD) — Class diagrams, UML, SOLID in practice
- **Unit 7:** System Design — Scalability, CAP theorem, consistent hashing, CQRS
