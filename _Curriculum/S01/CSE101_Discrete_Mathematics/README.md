# CSE101 — Discrete Mathematics

**Semester:** S01 | **Hours:** ~20h | **Prerequisite:** None

## Description

Discrete Mathematics provides the mathematical foundations essential for computer science: propositional and predicate logic, set theory, relations, functions, combinatorics, graph theory, and proof techniques including induction and contradiction. These topics underpin algorithm analysis, database theory, cryptography, and formal verification.

## Learning Outcomes

- Construct and evaluate logical arguments using propositional and predicate logic
- Apply proof techniques (direct, contrapositive, induction, contradiction) to mathematical claims
- Work with sets, relations, functions, and their properties
- Count combinatorial structures using permutations, combinations, and recurrence relations
- Model problems with graphs and reason about graph-theoretic properties

## Syllabus Outline

- Propositional logic, truth tables, logical equivalences
- Predicate logic, quantifiers, proof strategies
- Set theory: operations, cardinality, power sets
- Relations and functions: properties, inverses, compositions
- Combinatorics: permutations, combinations, pigeonhole principle
- Recurrence relations and solving recurrence equations
- Graph theory: paths, cycles, trees, connectivity
- Boolean algebra and digital logic foundations
