## Learning Outcomes

- Manipulate propositional logic, set theory, and proof techniques
- Write production-quality Java and TypeScript programs
- Operate confidently in Linux/CLI environments with Git version control
- Reason about memory layout, time complexity, and data representation

## Syllabus Overview

- **Weeks 1–4:** Memory model, arrays, Big-O, hash tables
- **Weeks 5–8:** Linked lists, stacks, queues, trees, heaps
- **Weeks 9–12:** Sorting, recursion, dynamic programming, graphs
- **Weeks 13–16:** Capstone 1 — DSA Toolkit in Java
