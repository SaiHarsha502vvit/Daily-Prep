# CSE102 — Programming Fundamentals

**Semester:** S01 | **Hours:** ~20h | **Prerequisite:** None

## Description

Programming Fundamentals builds solid foundations in imperative and object-oriented programming using Java and TypeScript. Topics include types, variables, control flow, functions, classes, interfaces, generics, exceptions, collections, file I/O, and unit testing. Emphasis is placed on writing clean, idiomatic code that compiles cleanly and passes tests.

## Learning Outcomes

- Write and debug Java programs using variables, control structures, and methods
- Apply OOP principles: encapsulation, inheritance, polymorphism
- Use generics, collections, and exception handling idiomatically
- Write unit tests with JUnit and verify correctness
- Transition seamlessly between Java and TypeScript environments

## Syllabus Outline

- Types, variables, operators, expressions, control flow
- Methods, recursion, pass-by-value semantics
- Classes, objects, interfaces, abstract classes
- Generics, collections (List, Map, Set), iterators
- Exceptions, assertions, defensive programming
- Unit testing with JUnit, test-driven development
- File I/O, serialization basics
- JavaScript/TypeScript equivalents for all above topics
