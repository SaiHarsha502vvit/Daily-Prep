# CSE104 — Introduction to Computer Systems

**Semester:** S01 | **Hours:** ~15h | **Prerequisite:** None

## Description

Introduction to Computer Systems demystifies the layers beneath high-level code: binary representation, boolean logic, CPU instruction cycles, memory hierarchy (cache, RAM, disk), process isolation, the Linux shell environment, Git version control workflows, and memory layout of common data structures. The goal is to develop an accurate mental model of what the machine actually does.

## Learning Outcomes

- Explain how integers, floats, and strings are represented in binary and hex
- Navigate and operate a Linux system using the shell (bash)
- Use Git for version control: branching, merging, rebasing, stash
- Describe the memory layout of arrays, linked lists, and objects on heap/stack
- Reason about cache locality, pointer arithmetic, and CPU memory access patterns

## Syllabus Outline

- Binary, hex, two's complement, floating-point representation
- Boolean algebra, logic gates, combinational circuits
- Linux CLI: file system, processes, pipes, environment
- Git workflows: init, add, commit, branch, merge, rebase, stash
- Memory model: stack vs heap, pointer arithmetic, buffer overflow
- Memory hierarchy: cache lines, locality, cache-friendly code
- Process and memory layout of a running Java/JS program
- Developer tools: make, gdb/lldb, valgrind basics
