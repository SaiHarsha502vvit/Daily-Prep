# Semester 6 — Backend & DevOps

| Code   | Course                           | Hours |
| ------ | -------------------------------- | ----- |
| CSE601 | Spring Boot & Microservices      | ~30h  |
| CSE602 | API Design & Testing             | ~20h  |
| CSE603 | DevOps & CI/CD                   | ~20h  |
| CSE604 | Java Concurrency & JVM Internals | ~20h  |

**Prerequisites:** [Semester 3 — Software Engineering Core](../S03/README.md) + [Semester 4 — Systems & Networking](../S04/README.md) (S04 can be taken concurrently with S06)

S06 is parallel with S05 but has an additional S04 prerequisite (networking basics needed for microservices and DevOps).

## Skills Covered

- Spring Boot 3.x: auto-configuration, dependency injection, reactive programming (WebFlux)
- Microservices: service discovery, load balancing, circuit breakers, API gateways
- REST API design: resource modeling, versioning, HATEOAS, OpenAPI
- Testing: contract testing, integration testing, performance testing, testcontainers
- DevOps: containerization, CI/CD pipelines, IaC, monitoring, observability
- JVM internals: memory model, GC algorithms, class loading, JIT compilation
- Java concurrency: ForkJoinPool, CompletableFuture, Structured Concurrency, virtual threads

## Study Guide

- Begin with [CSE604](./CSE604_Java_Concurrency_And_JVM_Internals/README.md) for JVM fundamentals (needed for Spring Boot)
- Progress through [CSE601](./CSE601_Spring_Boot_And_Microservices/README.md) for Spring Boot mastery
- Continue to [CSE602](./CSE602_API_Design_And_Testing/README.md) for API design
- Finish with [CSE603](./CSE603_DevOps_And_CICD/README.md) for DevOps pipeline

## Parallel Path

This semester is designed to run alongside [Semester 5 — Frontend & DevEx](../S05/README.md). Combined, S05 + S06 provide the full-stack skill set required for Semester 7.
