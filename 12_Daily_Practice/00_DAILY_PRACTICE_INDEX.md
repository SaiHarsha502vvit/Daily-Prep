```

+----------+--------+------------------------------------------------+
| Block    | Time   | What You Do                                    |
+----------+--------+------------------------------------------------+
| SPRING   | 90 min | Spring Boot: theory + code-along               |
| SQL      | 45 min | SQL deeper practice / project work             |
| REVIEW   | 45 min | Redo weak problems from the week               |
+----------+--------+------------------------------------------------+

Every Sunday = REVIEW DAY (no new topics, consolidate + redo)
```
