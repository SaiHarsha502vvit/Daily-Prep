# Folder Context: 17_TypeScript

## Purpose

Teach TypeScript types, inference, narrowing, generics, utility types, and practical typed application design.

## Writing Style

- Show type problem first.
- Explain inference and constraints.
- Prefer practical examples over abstract type tricks.
- Include failure modes and compiler feedback.

## Boundaries

Java generics belong in `07_Modern_Java`. React examples belong in `15_React_Frontend` unless the lesson is primarily about TypeScript.

## Update Triggers

Update this file when TypeScript style, type-system boundaries, or practical typing rules change.
