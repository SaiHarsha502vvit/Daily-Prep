# Folder Context: 08_SQL

## Purpose

Teach SQL from foundations to joins, windows, recursive CTEs, analytics, transactions, indexing, optimizer behavior, and database internals.

## Writing Style

- Database-first reasoning.
- Show query shape, result shape, and execution implications.
- Include constraints such as data volume, indexes, nulls, duplicates, isolation, and update frequency.
- Prefer SQL examples over application-language examples.

## Boundaries

Java exception hierarchy, React state, CSS layout, and pure DSA drills do not belong here unless the section explicitly bridges SQL to application behavior.

## Update Triggers

Update this file when SQL module boundaries, analytics conventions, or database-internals rules change.
