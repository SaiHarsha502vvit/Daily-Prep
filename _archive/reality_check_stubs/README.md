# Reality Check Stubs (archived 2026-07-25)

These 17 files were **accidental byproducts** of an interrupted Reality-Check-writing session (June–July 2026): an `Add-Content` batch appended Reality Check sections to filenames that didn't exist in the modules anymore (older pre-rename chapter names), silently creating new 15-line files containing only a BOM + one `## Reality Check` section.

They were never tracked by git and collided with the real chapters' numbering
(e.g. `10_Bit_Manipulation.md` sat next to the canonical `10_Bit_Manipulation_Complete.md`).

Archived instead of deleted per the repo's no-loss rule. The filename prefix
(`03_Algorithms__`, `07_Modern_Java__`, `08_SQL__`) records where each stub sat.
The canonical chapters all carry their own Reality Check sections (rounds 1–6),
so nothing here is load-bearing — but if any stub's misconception wording turns
out better than the canonical one, it can be salvaged from here.
