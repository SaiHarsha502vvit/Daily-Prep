## 🧠 THE 5-STEP METHOD (Memorize This!)

```
PROBLEM: Any coding problem

STEP 1: Name the pattern
        ↓
        "This is sliding window" / "This is two pointers"
        BEFORE writing ANY code!

STEP 2: Write skeleton ONLY
        ↓
        for (int j = 0; j < n; j++) {
            // Empty for now
        }
        NO logic yet!

STEP 3: Add the invariant
        ↓
        // Invariant: j - i + 1 = window size
        The ONE thing that stays true

STEP 4: Layer the logic (ONE PIECE AT A TIME)
        ↓
        First: include arr[j]
        Then: check if window ready
        Then: slide window
        NOT all at once!

STEP 5: Edge cases LAST
        ↓
        if (n == 0) return;
        if (k > n) return;
        AFTER everything works
```

**When you freeze:** Go back to Step 1. Don't try to code without structure.

### If Test Cases Fail:
