# Projects — Your Portfolio Workspace

This folder is where your actual Flutter project code lives as you work through the bootcamp. Create one subfolder per project (`profile_app/`, `shopping_app/`, ...) and initialise each as its own git repository — your commit history on these projects **is** your portfolio.

## Workflow Per Project

1. Read the full spec file before writing any code — screens, models, features
2. `flutter create <project_name>` inside this folder
3. Commit early, commit often — reviewers read commit history
4. Finish the spec's shipping checklist before calling it done
5. Record a short screen capture for your portfolio when complete
