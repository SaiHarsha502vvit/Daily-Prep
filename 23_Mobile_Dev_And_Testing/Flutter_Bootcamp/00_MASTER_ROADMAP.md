# Flutter Bootcamp: Zero to Production
### 6-Month Structured Course — Scratch to Pro

---

## Course Philosophy

This is not a copy-paste tutorial course. Every week follows the same loop:

```
Understand WHY  →  Write the code  →  Hit the wall  →  Build something real
```

You don't watch someone build an app. You build it yourself, hit real problems, and figure them out. That's how professional Flutter developers actually work.

Each file in this course covers exactly ONE week. No 600-line dumps. No "complete this topic" checkboxes. Just focused, honest work.

## University Corner

This course is structured with academic rigor alongside practical skills.

**MIT influence (6.S062 / Mobile Computing)**
- Systems thinking: understand the rendering pipeline, not just the API
- Complexity analysis applied to UI: why widget trees rebuild, and when it matters
- Formal state machine thinking in navigation and state management

**KTH (DD2390 / Software Engineering)**
- Requirement-driven development: every project starts with a spec
- Test-driven thinking: tasks always include how to verify your work
- Code review mindset: clean code, readable names, no magic numbers

**TU Munich (IN2258 Praktikum)**
- Structured design patterns (every pattern has a name, a diagram, a trade-off)
- Systematic debugging methodology
- Documentation discipline (your code should explain itself)

## Daily Study Rhythm

Each study session should follow this structure:

```
[30 min]  Read the week's concept file — understand WHY first
[60 min]  Work through the code examples, type them out (don't copy)
[30 min]  Do 1-2 tasks from the task list
[30 min]  Tackle the week's challenge
```

On weekends, spend 2-3 hours on the project for that phase.

## Before You Start — Checklist

- [ ] Flutter SDK installed (stable channel: `flutter channel stable && flutter upgrade`)
- [ ] Dart SDK included with Flutter — no separate install
- [ ] VS Code with Flutter + Dart extensions installed
- [ ] Android Studio installed (for Android emulator) OR physical device
- [ ] Git set up
- [ ] Run `flutter doctor` — all green
