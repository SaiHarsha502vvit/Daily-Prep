# Phase 2 — Core UI Mastery
### Month 2 | Weeks 7-11

---

## What This Phase Is About

Phase 1 got you moving. Phase 2 makes you confident with UI. By the end you can build any screen from a design mockup — complex scrolling layouts, validated forms, smooth animations, gesture interactions, and properly componentised widget code.

The capstone: a **Shopping App UI Clone** — you pick a real app and replicate its UI from scratch.

## What You'll Build This Phase

**Weekly labs:**
- Contact list with alphabetical sticky headers + swipe to delete (Week 07)
- Multi-section job application form with real-time validation (Week 08)
- Animated onboarding flow with staggered entrance animations (Week 09)
- Swipeable card stack (Tinder-style) with gesture physics (Week 10)

**Phase capstone:**
A full shopping app UI clone (Zomato / Myntra / Swiggy) with:
- Collapsing SliverAppBar on restaurant page
- Infinite scroll product feed
- Validated checkout form
- Hero animation between listing and detail
- Cart state shared across tabs

---

## Phase 2 Self-Assessment

After completing all 5 weeks, you should be able to:

- Build any standard scrollable layout without looking up widget names
- Write a form with per-field validators and a clean submit flow
- Add implicit animations to any widget in under 2 minutes
- Detect tap, double-tap, long-press, drag, and swipe on any widget
- Extract UI code into focused, reusable custom widgets
- Explain the difference between a tight and a loose constraint
