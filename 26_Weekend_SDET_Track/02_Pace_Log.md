## Cold-Recall Checklist

At the checkpoint, explain each of these **out loud, without notes**. Tick only if you genuinely could.

- [ ] The event loop — call stack, task queue, microtask queue, and what order they run in
- [ ] What a closure is, and *why* it keeps a variable alive after the function returned
- [ ] `==` vs `===` — and the one case where `==` is the right choice
- [ ] Why `var` in a loop with callbacks gives the same value every time, and what `let` changes
- [ ] Event bubbling vs capturing, and what delegation is for
- [ ] What an execution context holds, and what pushes/pops the call stack
- [ ] Why `this` breaks when you pass a method as a callback

Anything unticked goes on the re-read list before Block 2 starts.
