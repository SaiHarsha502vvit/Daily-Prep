# Folder Context: 10_Enterprise_Systems

## Purpose

Teach ERP, DDD, finance, order, inventory, workflow, saga, outbox, and enterprise production systems.

## Writing Style

- Business process first.
- Then domain model, data flow, transaction boundary, and failure mode.
- Connect DSA and algorithms to production modeling, not isolated puzzles.
- Use realistic enterprise examples.

## Boundaries

Pure Java language mechanics belong in `07_Modern_Java`. Pure SQL tutorials belong in `08_SQL`. Pure DSA theory belongs in `02_Data_Structures` and `03_Algorithms`.

## Update Triggers

Update this file when enterprise workflows, domain boundaries, or business-system patterns are added or moved.
