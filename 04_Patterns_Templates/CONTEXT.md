# Folder Context: 04_Patterns_Templates

## Purpose

Own reusable coding patterns, templates, trigger maps, and constraint-based selection guides.

## Writing Style

- Pattern signal first.
- Constraint lens near the top.
- Show brute force to optimized rewrite.
- Include "works when" and "breaks when".
- Keep templates practical and language-friendly.

## Boundaries

Full theory chapters belong in `03_Algorithms` or `02_Data_Structures`. This folder should help choose and apply patterns quickly.

## Update Triggers

Update this file when pattern selection rules, constraint overrides, or template conventions change.
