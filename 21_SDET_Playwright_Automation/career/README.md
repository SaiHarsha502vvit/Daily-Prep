# Career System

This folder is where the SDET module turns into job offers. Everything in here is for **outside-the-codebase work** — your CV, your portfolio, your interview prep, your security thread.

Update these files as you progress. They are living documents, not one-shot deliverables.

| File                                       | What it is                                        | Update cadence               |
| ------------------------------------------ | ------------------------------------------------- | ---------------------------- |
| [PROGRESS.md](PROGRESS.md)                 | Checklist of every chapter + challenge + capstone | After each finish            |
| [INTERVIEW_BANK.md](INTERVIEW_BANK.md)     | 50 system design Qs + STAR bank                   | Weekly during interview prep |
| [PORTFOLIO_PLAN.md](PORTFOLIO_PLAN.md)     | What public repos you ship and when               | Monthly                      |
| [RESUME_BULLETS.md](RESUME_BULLETS.md)     | Project → résumé line mapping                     | After each project ships     |
| [DEVSECOPS_THREAD.md](DEVSECOPS_THREAD.md) | Security/DevSecOps seeds across all chapters      | After each new chapter       |
