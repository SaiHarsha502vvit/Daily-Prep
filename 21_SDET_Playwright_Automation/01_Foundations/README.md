# Stage 1 — Foundations

**Navigation**: [Module front door](../README.md) | [Stage 2 — Test Architecture →](../02_Test_Architecture/README.md)

Install Playwright, write your first test, and learn how it finds elements — plus the two tools you'll use every single day: the Trace Viewer (debugging) and `playwright.config.ts`.

**After this stage you can:** Write and debug a small test suite on your own machine, and explain why Playwright tests don't need `sleep`.
