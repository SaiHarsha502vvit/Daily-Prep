# Folder Context: 02_Data_Structures

## Purpose

Teach data structures from memory model to operations, variants, Java collections, and production behavior.

## Writing Style

- Start with why the structure exists.
- Explain memory/layout and operation cost.
- Include constraints, invariants, and when the structure breaks.
- Bridge to Java implementation details when useful.

## Boundaries

Algorithm patterns belong mostly in `03_Algorithms` and `04_Patterns_Templates`. Use this folder when the data structure itself is the main lesson.

## Update Triggers

Update this file when new data structure families, advanced variants, or production-use rules are added.
