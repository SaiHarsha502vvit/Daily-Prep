# Folder Context: 02_Data_Structures

## Purpose

Teach data structures from memory model to operations, variants, Java collections, and production behavior. Also contains the **University Methodology Layer** (`A1_DS..A4_DS`) — the proof-based, complexity-based, lower-bound, and randomized DS chapters that mirror the algorithm-side `A1..A4` in `03_Algorithms/`.

## Writing Style

- Start with why the structure exists.
- Explain memory/layout and operation cost.
- Include constraints, invariants, and when the structure breaks.
- Bridge to Java implementation details when useful.
- Catalog chapters may include a "🎓 University Proof Corner" near the top — a 1-3 page compression of 1-3 proofs from the `A*_DS` chapters, with MIT/KTH/RWTH/TUM attribution and a "Full proofs: [link]" footer. See `00_CONTEXT/DECISIONS.md` D015.

## Boundaries

- Algorithm patterns belong mostly in `03_Algorithms` and `04_Patterns_Templates`. Use this folder when the data structure itself is the main lesson.
- The `A*_DS` chapters are the rigorous, university-style foundation. Catalog chapters (`01a..05`) teach implementation; Proof Corners link to the `A*_DS` chapters for the underlying theory.

## Update Triggers

Update this file when new data structure families, advanced variants, production-use rules, or university-methodology additions are made.
