# Folder Context: 07_Modern_Java

## Purpose

Teach Java, JVM, Spring Boot, JPA, HTTP, security, testing, and distributed Java service design.

## Writing Style

- Explain language/runtime behavior before framework behavior.
- Use production Java examples.
- Include lifecycle, memory, threading, transaction, and debugging reasoning.
- Keep Spring challenges tied to the local Spring topic.

- Functional-programming foundations live in the `Ch06a`–`Ch06g` series (one topic per page, Java 21, laws and examples verified by running code); follow [`Ch06a`](Ch06a_FP_Learning_Path_And_Book_Map.md) for order.

## Boundaries

Pure SQL belongs in `08_SQL`. Pure DSA belongs in `02_Data_Structures`, `03_Algorithms`, or `04_Patterns_Templates`. Frontend belongs in `15_React_Frontend` through `19_Frontend_Integration`.
