Description:
Write a program to check if the given number is a Prime Number or not and if  it's a Prime Number, then print it's position.


Constraints:
Input             :- First Line of Input Consists of One Integer Value ( N ) .

Output          :-  If N is not a prime number, print: Not a Prime

                         If N is a prime number, print: Prime, Position = X.

Constraints  :- Given Input Must be Greater than Zero or else Print "Invalid Input".


Example:
Input 1:    7

Output 1: Prime, Position = 4.

 

Input 2:  19

Output 2: Prime, Position = 8.

 

Input 3:   10

Output 3: Not a Prime


Explanation:
Input 1: 7

Explanation: Prime numbers are 2, 3, 5, 7. So, 7 is the 4th prime.


Input 2: 19

Explanation: Prime numbers are 2, 3, 5, 7, 11, 13, 17, 19. So, 19 is the 8th prime.

 

Input 3: 10

Explanation: Given number is not a Prime. So, print Not a Prime.


Your Code: java
import java.util.*;


public class PositionOfPrime {
    public static void main(String [] args){
        Scanner sc = new Scanner(System.in);
        
        int gpn = sc.nextInt();
        
        int count=0;
        int num=1;
        boolean flag = true;
        int i = 1;
        while(i<=gpn){
            num++;
            if(isPrime(num)){
                if(num==gpn){
                        System.out.println("Prime, Position = "+count+".");
                    flag=false;
                }
                count=count+1;
            }
            i++;
        }
        
        if(flag){
            System.out.println("Not a Prime");
        }
    }
    
  
    
    
    
    public static boolean isPrime(int num){
        if(num<=1) return false;
        
        for(int i=2;i<(num/2);i++){
            if(num%i==0){
                return false;
            }
        }
        return true;
    }
}

Constraints:
Input:

First line contains an integer s

Second line contains an integer e

Third line contains an integer k

Output:

Print all numbers in the range [ s , e ] whose digit sum is divisible by k

If no such numbers exist, print No Numbers

Example:
Input1  :          4
		   35
		   5

Output1 :        5 14 19 23 28 32

Input2  :          120
	           150		
		   7

Output2 :        124 133 142 149

                        35

                        5

Output1 :        5 14 19 23 28 32

5 → 5 → divisible by 5 

14 → 1 + 4 = 5 → divisible by 5 

19 → 1 + 9 = 10 → divisible by 5 

23 → 2 + 3 = 5 → divisible by 5 

28 → 2 + 8 = 10 → divisible by 5 

32 → 3 + 2 = 5 → divisible by 5

124 → 1 + 2 + 4 = 7 → divisible by 7

import java.util.*;

public class DigitSum {
    public static void main(String[] args){
        Scanner sc= new Scanner(System.in);
        
        int start = sc.nextInt();
        int end = sc.nextInt();
        int k = sc.nextInt();
        
        if(end<0){
            end*=(-1);
        }
        
        if(start<0){
            start*=(-1);
        }
        
        if(start>end){
            start=start+end;
            end=start-end;
            start=start-end;
        }
        
        
        // System.out.println(start+" Start");
        // System.out.println(end+" End");
        
        
        int count=0;
        for(int i=start+1;i<end;i++){
           int sum=0;
           int temp=i;
           while(temp>0){
                sum+=temp%10;
                // System.out.println(sum);
                temp=temp/10;
                // System.out.println("remaining of "+(i)+" "+temp);
           }
           if(sum%k==0){
               System.out.print(i+" ");
               count++;
           }
        }
        if(count==0){
            System.out.println("No Numbers");
        }
        
    }
}
