# Folder Context: 18_CSS_Complete

## Purpose

Teach CSS foundations, layout systems, responsive design, architecture, UI styling, and visual reasoning.

## Writing Style

- Layout mental model first.
- Show constraints: viewport, content size, flow, stacking, specificity, cascade.
- Use practical UI examples.
- Explain why layout breaks and how to debug it.

## Boundaries

React component logic belongs in `15_React_Frontend`. JavaScript behavior belongs in `16_JavaScript`. Build tooling belongs in `19_Frontend_Integration`.

## Update Triggers

Update this file when CSS architecture, layout conventions, or UI design process changes.
